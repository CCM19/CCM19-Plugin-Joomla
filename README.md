# CCM19 Integration



## Plugin to integrate the CCM19 cookie banner into joomla.

### Installation via package-installation

For the installation enter "make" into the terminal.
In the Joomla backend go to System->Install->Extensions and upload the package there.

### usage
To use this plugin, you will need a CCM19 script code. You can receive one from the [official site](https://www.ccm19.de/en/)

After receiving one, insert and save it in the Joomla Admin > System > Plugins > System - CCM19

---
## Plugin zur Integration des CCM19 in Joomla.

### Installation via Paket-installation

Zur Installation "make" im Terminal eingeben.
Im Joomla Backend System->Installieren->Erweiterungen und dort das Packet hochladen.

### Anwendung

Zur Benutzung des Plug-ins ist ein Skript von CCM19 erforderlich. Dieses ist auf der [offiziellen Seite](https://www.ccm19.de/) erhältlich.

Nach erhalt des Skriptes müssen Sie es nur noch in Joomla Admin > System > Plugins > System - CCM19 einfügen und speichern.
